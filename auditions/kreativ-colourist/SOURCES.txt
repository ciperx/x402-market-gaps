Grade
-----
after.mp4 is before.mp4 with look.cube applied by ffmpeg lut3d, nothing else.
look.cube is a 33x33x33 3D LUT (35937 entries, 0..1 domain) built by gen_lut.py
from this transform, in order:

  1. Black lift: x = 0.032 + 0.968 x. Raises the floor so no shadow goes to 0.
  2. Gentle S-curve: x = 0.80 x + 0.20 smoothstep(x). Soft contrast, endpoints kept.
  3. Warm balance: R x 1.055, G x 1.005, B x 0.935, with +0.006 R and -0.002 B
     weighted by (1 - x), so shadows warm gently instead of turning blue.
  4. Hue selective saturation in HSV: +12 percent for greens near 120 deg,
     +10 percent for skies near 215 deg, gaussian weighted, skin hues untouched.
  5. Highlight shoulder: above 0.86 a tanh rolloff maps 1.0 to about 0.967,
     so whites keep headroom and nothing clips.
  6. Golden highlight tint: +0.010 R, +0.003 G, -0.008 B weighted by mean(x)^2.

Reproduction commands
---------------------
  ffmpeg -ss 157.0 -t 16.0 -i SurpriseForJ.mp4 -map 0:v:0 -map 0:a:0 \
    -c:v libx264 -preset slow -crf 16 -pix_fmt yuv420p \
    -colorspace bt709 -color_primaries bt709 -color_trc bt709 \
    -c:a aac -b:a 128k -movflags +faststart before.mp4

  ffmpeg -i before.mp4 -vf lut3d=look.cube \
    -c:v libx264 -preset slow -crf 16 -pix_fmt yuv420p \
    -colorspace bt709 -color_primaries bt709 -color_trc bt709 \
    -c:a copy -movflags +faststart after.mp4

    average 45.49 dB, y 44.17, u 50.73, v 51.18, min 43.56, max 48.46

Signal range, measured with ffmpeg signalstats over every frame:
  before.mp4 YMIN 0, YMAX 246
  after.mp4  YMIN 5, YMAX 239
So the grade lifts the blacks (floor 0 to 5) and tames the highlights
(ceiling 246 to 239) instead of crushing or clipping them.
blackdetect (d=0.1, pix_th=0.10) reports no black segment in after.mp4.
